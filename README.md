# iRede — Smart Contracts (iRede.c & Certificados)

Contratos inteligentes do sistema de certificados iRede na blockchain
**Polygon**: a moeda utilitária **Utility iRede Coin (iRede.c)** e o
registro/ancoragem dos certificados de participação dos Residentes e Alunos.

Este repositório é um **submódulo** do projeto principal
[carlosdelfino/irede_web3_moeda_certificado](https://github.com/carlosdelfino/irede_web3_moeda_certificado).

## Escopo do módulo

- Token utilitário iRede.c (padrão ERC-20 ou equivalente) e suas regras de emissão/distribuição.
- Contrato de registro de certificados (hash/ancoragem, emissor, revogação).
- Scripts de deploy e verificação nas redes Polygon (Amoy/Mainnet).
- Auditoria e hardening conforme as regras de segurança do projeto.
